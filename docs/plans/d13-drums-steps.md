# D13. 드럼 보기, 스텝 입력, 화음 펼치기

> 작성일: 2026-10-22. 계기: 상용 DAW 와 견준 빈자리 표(D8 1절)의 편집 칸 "드럼 격자 편집기, 스텝 입력". 드럼 트랙도 피아노 건반 128 줄에서 고쳤고
> (이름이 있는 건반 사이에 빈 줄이 끼었다), 음을 넣는 길은 두 번 클릭과 실시간 녹음뿐이었다.

## 1. 목표

드럼과 타악기 트랙은 이름 있는 건반만 줄로 보이고 칸을 눌러 친다. 재생을 멈춘 채 건반으로 음을 한 칸씩 넣는다. 화음을 아르페지오와 스트럼으로 펼친다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 드럼 보기의 줄 | 악기의 건반 이름(`keyNames`)이 있는 건반과 그 트랙이 쓴 건반, 높은 음이 위 (피아노 보기와 같은 방향). 이름이 같은 건반이 여럿이면 음 이름을 붙인다 ("탐 2 (B2)") | 곡 JSON 은 그대로 음높이다. 쓴 건반을 빼면 그 음을 고칠 수 없다 |
| 언제 | 건반 이름이 있는 악기(`drum-kit`, 내장 드럼 신스 넷, `percussion`)의 트랙은 드럼 보기로 연다. 피아노 롤 왼쪽의 "드럼 보기" 단추로 끄고 켜며, 트랙 이름마다 기억한다 (앱이 열려 있는 동안) | 화면 상태는 곡에 쓰지 않는다 |
| 그리기 | 친 자리의 마름모 (세기가 클수록 크고 밝게), 길이는 옅은 선. 줄 높이는 18 px 위 | 북은 길이보다 친 자리가 중요하다 |
| 처음 자리 | 쓰인 줄이 다 들어가면 가운데에, 아니면 가장 많이 친 줄을 가운데에 | 하이햇처럼 촘촘한 줄이 먼저 보인다 |
| 편집 | 빈 칸을 누르면 그 칸(격자)에 격자 한 칸 길이로 친다 (마지막 세기). 끌면 사각형 고르기, 치기를 끌면 옮기기(위아래는 줄 단위), 두 번 클릭은 지우기. 빈 칸의 두 번 클릭은 치기 하나를 남긴다 | 상용 드럼 편집기의 클릭으로 치기 |
| 스텝 입력 | 편집 > 스텝 입력 (⌘⇧E). 멈춘 동안 자판 연주나 MIDI 건반으로 친 음을 재생 위치(격자에 맞춘다)에 격자 길이로 넣고 한 칸 나아간다. 함께 누른 음은 모두 뗄 때 한 칸에 (화음). 세기는 MIDI 건반의 세기, 자판은 100 | 실시간으로 칠 수 없는 빠른 음형과 화음을 넣는다 |
| 스텝 입력의 키 | 고른 음표가 없을 때 → 쉼표(한 칸 나아가기), ← 물러서기, 백스페이스는 마지막 칸(쉼표 포함)을 지우고 물러선다. 재생 위치를 옮기면 그 자리부터. 재생 중에는 연주만 하고 넣지 않는다. 칸마다 편집 하나 | |
| 화음 펼치기 | 엔진의 `arpeggiateNotes` (같은 시작의 음 둘 넘는 화음을 그 길이 동안 격자마다 한 음씩: 위로, 아래로, 위아래로. 음마다의 세기와 아티큘레이션을 지키고 가사는 처음 음에만), `strumNotes` (낮은 음이나 높은 음부터 15, 30, 60 ms 씩 늦추고 끝은 지킨다). 음표 다듬기 메뉴의 "화음 펼치기" | 음은 곡에 적혀 사람이 본다 (재생 때 만드는 아르페지에이터를 두지 않는다) |

## 3. 체크리스트

- [x] 앱: 스텝 입력 (자판, MIDI 입력, 화음, 쉼표, 물러서기, 지우기, 명령과 메뉴)

## 4. 확인한 것

- 스냅숏: 「새벽 세 시」의 `Kit` 트랙 (MuldjordKit): 쓴 건반과 이름 있는 건반 22 줄 가운데 8분음표 닫힌 하이햇 줄이 가운데에, 세기에 따라 마름모 크기가 다르다.
  처음에는 맨 위 줄부터 보여 하이햇이 아래로 밀렸고 "탐 2" 두 줄이 같은 이름이라 고쳤다.
- 앱 `--edit-test` 드럼 보기 12건: `synth.edm-drums` 의 줄은 이름 있는 건반과 쓰인 70 (높은 음부터, 이름 없는 54 는 없다), 빈 칸 클릭은 2 박에 16분음표 치기,
  빈 칸의 두 번 클릭은 치기 하나(처음에는 둘째 클릭을 뗄 때 하나 더 넣었다), 치기의 두 번 클릭은 지우기, 53 의 치기를 한 줄 위로 끌면 55, 피아노 보기 고르기와 트랙마다의 기억, 실행 취소.
- 앱 `--edit-test` 스텝 입력 14건: 2.1 박의 재생 위치는 2 박(8분음표 격자), 누르고 있는 동안은 쓰지 않고 C E 를 모두 떼면 2 박에 8분음표 화음, 쉼표, 다음 음, 마지막 칸 지우기 셋
  (음, 쉼표, 화음), MIDI 입력의 세기 90, 재생 위치를 옮기면 그 자리, 물러서기, 끄면 넣지 않는다, 실행 취소.
- 엔진 단위 시험: C E G 한 박을 16분음표로 위로 C E G C, 아래로 G E C G, 여섯잇단 16분 위아래로 C E G E C E, 셋잇단 8분은 셋. 스트럼 0.05 박.

## 5. 남은 것

- 악보 보기는 없다 (D8 1절 표).
- 드럼 보기에 줄마다의 이름 바꾸기나 줄 순서 바꾸기(드럼 맵)는 없다. 줄 이름은 악기 정의의 `keyNames` 다.
- 스텝 입력의 길이는 격자다 (점음표나 잇단음은 격자 상자에서 고른다).
