# D24. VCA

> 작성일: 2026-10-23. 계기: D8 의 간격 표에 "뒤로"로 남은 믹서 줄. 상용 DAW 의 VCA 는 소리를 모으지 않고 여러 채널의 페이더를 함께 움직인다
> (버스로 모으면 효과와 센드의 자리가 바뀌지만 VCA 는 각 채널의 페이더 자리에서 곱한다).

## 1. 목표

곡에 VCA 를 두고 트랙과 버스를 넣는다. VCA 의 게인(곡선 포함)은 속한 채널의 페이더 게인에 더해지고, VCA 의 뮤트는 속한 채널을 끈다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 곡 | 맨 위 `"vcas": [ { "name", "gainDb", "mute", "automation": { "gainDb": [...] } } ]`, 트랙과 버스의 `"vca": "이름"` (채널 하나에 VCA 하나). 이름은 VCA 끼리 하나뿐, 없는 이름은 검사 오류 | 곡의 형식은 JSON 하나 |
| 엔진 | 곡을 읽을 때 `resolveVcas` 가 채널마다 VCA 의 값을 `MixerSettings` 의 따로 된 칸(`vcaDb`, `vcaMute`, `vcaLane`)에 푼다. 채널 자신의 `gainDb`, `mute` 는 그대로라 편집과 저장에 섞이지 않는다. 게인은 `totalGainDb()` (채널 + VCA), 뮤트는 `muted()` | 게인을 계산하는 곳(오프라인의 트랙 사슬과 버스, 실시간의 페이더)이 같은 함수를 지난다 |
| 곡선 | 페이더 곡선에 VCA 곡선을 dB 로 더한다 (32 샘플 격자, `FaderLanes::vca`). 곡선이 하나라도 있으면 고정값도 곡선 쪽이 들고 있어, 실시간 반영은 고정값이 바뀌어도 곡선을 바꿔 끼운다 | 채널의 곡선 칸이 지금까지 고정 밸런스를 바꿔도 곡선 쪽의 옛 값을 쓰던 것도 함께 고쳤다 |
| 실시간 | VCA 를 고치면 속한 채널의 믹서가 바뀐 곡이 되어 `apply` 가 페이더를 잇거나 곡선을 바꿔 끼운다 (재생기를 다시 만들지 않는다) | |
| 앱 | 믹서의 버스 뒤에 VCA 스트립(이름, 페이더, 게인 값, 뮤트, 속한 채널 수), "+ VCA" 단추, 트랙과 버스 이름 메뉴의 VCA 하위 메뉴(없음, VCA 마다, 새 VCA 를 만들어 넣기), 속한 채널의 이름 아래 `[VCA 이름]`. 이름 바꾸기와 지우기는 속한 채널의 `vca` 도 함께 고친다 (편집 하나). 속한 트랙의 곡선 칸에 "VCA 게인 (이름)"이 늘 있다. 재생 중 VCA 페이더가 곡선을 따른다 | |

## 4. 확인한 것

- 오프라인: 트랙 -3 dB 와 VCA -6 dB (버스도 VCA 에)가 트랙 -9 dB, 버스 -6 dB 와 샘플까지 같다 (차이 0). VCA 의 곡선(부드러운 곡선 포함)이 같은 트랙 곡선과 1e-6 안에서 같고,
  실시간 재생이 그 오프라인과 1e-5 안. VCA 뮤트는 트랙 뮤트와 샘플까지 같고, 트랙 자신의 `mute` 는 거짓으로 남는다.
- 실시간 반영: VCA 를 0 에서 -12 dB 로 바꾼 곡을 재생 전에 반영하면 새로 만든 재생기와 같다 (차이 0). 곡선이 생기면 곡선을 바꿔 끼워 1e-6 안.
- 검사: 없는 VCA 이름, 같은 이름의 VCA, VCA 의 `gainDb` 밖 곡선이 오류.
- 앱: VCA 더하기, 트랙 넣기, VCA 페이더 -6 dB 가 트랙의 `vcaDb` 가 되고 트랙 자신의 게인은 그대로, 뮤트, 이름 바꾸기가 트랙의 `vca` 를 바꾼다, 버스와 함께 새 VCA, 지우기가 속한 채널을 풀어 준다,
  속한 트랙의 곡선 칸에서 두 번 눌러 VCA 곡선에 점을 넣는다, 일곱 편집을 되돌리면 처음 곡과 같다. 믹서 스냅숏에서 VCA 스트립과 `[Strings]` 표시를 확인했다.

## 5. 남은 것

- VCA 의 솔로, 채널 하나가 여러 VCA 에 속하기, VCA 안의 VCA, 곡선 쓰기(D19)의 VCA 페이더는 없다.
