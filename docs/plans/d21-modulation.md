# D21. 모듈레이션 효과와 노이즈 게이트

> 작성일: 2026-10-23. 계기: 상용 DAW 의 기본 효과 가운데 코러스, 플랜저, 페이저, 트레몰로(오토팬), 노이즈 게이트가 없었다.

## 1. 목표

내장 효과에 `chorus`, `flanger`, `phaser`, `tremolo`, `gate` 를 더한다. 트랙, 버스, 마스터 어디에나 걸고, 곡선(automation)과 앱의 효과 편집기를 쓴다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| LFO | 위상이 곡 위치만의 함수다: 곡의 샘플까지 지난 주기 수가 `rateHz * 초` 이거나, `rateBeats` 가 있으면 `템포 지도의 박 / rateBeats`. 블록 안에서는 32 샘플 격자 점 사이를 직선으로 잇는다 (`followsPosition`) | 실시간과 오프라인, 위치 옮기기, 반복의 되돌아가기에서 같은 자리가 같은 위상이다 (설계 원칙). 멈춘 동안은 그 자리의 위상에 붙든다 |
| 빠르기 곡선 | `rateHz` 와 `rateBeats` 는 곡선을 받지 않는다 | 빠르기를 바꾸면 위상이 지난 빠르기의 적분이라 곡 위치만의 함수가 아니게 된다 |
| 오른쪽 채널 | `phaseDeg` (0~180) 만큼 오른쪽 LFO 가 앞선다 | 스테레오 폭. 트레몰로는 180 이면 오토팬 |
| chorus, flanger | 지연 시간이 `delayMs` 와 `delayMs + depthMs` 사이를 0.5 - 0.5 cos 로 오간다. 4점 에르미트 보간, 되먹임(-0.95~0.95). 기본값만 다르다 (코러스 12 ms + 3 ms, 0.8 Hz, 되먹임 0, 90도; 플랜저 1 ms + 2 ms, 0.2 Hz, 되먹임 0.6, 0도) | 같은 구조다 |
| phaser | 1차 전역 통과 `stages` 단 (2~12, 짝수), 꺾임 주파수를 `lowHz` 와 `highHz` 사이에서 로그로 흔든다. 계수는 격자 점에서 쌍선형(미리 휜 주파수)으로 구해 잇는다. 되먹임은 마지막 단의 출력을 입력에 | 2단이면 꺾임 주파수에서 위상이 반 바퀴라 원음과 반씩 섞으면 지워진다 |
| tremolo | 크기 1 - depth * w(위상), w 는 사인, 삼각, 둥근 사각 (`shape`). 상태가 없다 | 사인과 삼각의 오토팬은 두 채널 게인의 합이 늘 2 - depth |
| gate | 두 채널의 봉우리(10 ms 로 내려오는 엔벨로프)가 `thresholdDb` 를 넘으면 열고, 3 dB 아래로 내려가 `holdMs` 가 지나면 닫는다. 닫힘은 `rangeDb` (-96 이면 0). 여는 데 `attackMs`, 닫는 데 `releaseMs` (1극) | 히스테리시스가 문턱 근처의 떨림을 막는다. 지연(미리 보기)은 두지 않는다 |
| 곡선 | `depthMs`, `feedback`, `mix` (chorus, flanger), `feedback`, `mix` (phaser), `depth` (tremolo) | |
| 앱 | 효과 더하기 메뉴에 다섯, 한국어 이름과 도움말, 트레몰로 모양 목록, 페이저 단 수 목록(선택지 목록은 값의 단위로 표기), 박 주기를 켜면 `rateHz` 를 지우고 끄면 첫 템포에서 같은 주기의 `rateHz` 를 쓴다 | 딜레이의 박 시간과 같은 방식 |

## 4. 확인한 것

- 코러스(10 ms + 4 ms, 오른쪽 180도)의 임펄스: 위상 0 에 멈춘 자리에서 왼쪽 480 샘플(10 ms), 오른쪽 672 샘플(14 ms), 반 주기 자리에서 반대.
  박에 맞춘 플랜저(120 BPM, 2 박 주기)는 0.25초 자리에서 2 ms (96 샘플). 되먹임 0.5 의 메아리가 1, 0.5, 0.25.
- 페이저 2단(600~4000 Hz)의 위상 0: 600 Hz 사인이 -154.7 dB, 5 kHz 와 60 Hz 는 -0.2 dB. 반 주기에서는 4 kHz 가 -40 dB 아래.
- 오토팬(3 Hz, 깊이 1, 180도): 두 채널 합의 오차 1e-4 안, 1/6 초에 왼쪽 0. 박 주기 트레몰로는 7777 샘플에서 300 샘플 블록으로 시작해도 처음부터 512 블록으로 처리한 것과 샘플 단위로 같다.
- 게이트(-40 dB 문턱, -80 dB 닫힘): -20 dBFS 의 소리는 0.00 dB, 뒤의 -60 dBFS 잡음은 -77.2 dB, 소리가 끝난 뒤 유지 시간 안은 1 dB 안.
- 실시간: 템포가 100 에서 140 BPM 으로 바뀌는 곡의 트랙(플랜저와 곡선 비율, 게이트), 버스(곡선 깊이의 코러스, 페이저), 마스터(박 주기 트레몰로)가
  오프라인 렌더와 1e-5 안에서 같고, 소리 없는 4.5 박으로 옮겨 재생한 뒤도 같다.
- 부하 (`music-render realtime`, 256 샘플 블록, saw-pad 두 트랙 6초): 한 트랙에 다섯 효과(12단 페이저)를 건 곡이 평균 0.062, 효과가 없을 때 0.041~0.052.
- 실제 소리의 판정은 저자가 한다.

## 5. 남은 것

- 게이트의 사이드체인 키(다른 트랙으로 여닫기)와 미리 보기, 익스팬더(비율), 디에서, 멀티밴드 압축기, 비트크러셔는 없다.
