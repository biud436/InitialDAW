# D25. 효과 프리셋과 효과 사슬

> 작성일: 2026-10-23. 계기: 상용 DAW 는 효과마다 공장 프리셋과 사용자 프리셋, 채널의 효과 사슬 저장과 불러오기를 갖춘다.
> 매번 매개변수를 처음부터 맞추지 않고 좋은 출발점에서 시작한다.

## 1. 목표

효과 편집기에서 기본 프리셋을 입히고, 지금 값을 내 프리셋으로 저장해 다른 곡에서도 입힌다. 채널의 효과 사슬을 통째로 저장해 다른 채널이나 곡에서 불러온다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 곡 | 프리셋을 입히면 값이 효과 객체에 그대로 들어간다. 곡은 프리셋을 가리키지 않는다 | 곡은 홀로 서야 한다 (프리셋이 바뀌거나 없어도 소리가 같다) |
| 기본 프리셋 | 엔진의 표(`effects/Presets`): 형식마다 영어 id 와 효과 객체, 화면 이름은 앱(`presetName`). EQ 넷, 압축기 넷, 리버브 넷, 딜레이 셋, 디스토션 둘, 스테레오 둘, 리미터 하나, 필터 둘, 덕킹 둘, 코러스 둘, 플랜저, 페이저, 트레몰로 둘, 게이트 (31개) | 엔진의 검사로 모두 확인한다. 에이전트와 생성기도 같은 값을 쓸 수 있다 |
| 입히기 | `withPreset`: 매개변수는 프리셋의 것으로 바꾸고 우회, 주석, 압축기의 사이드체인 키, 프리셋 뒤에도 곡선을 둘 수 있는 매개변수의 곡선은 남긴다. 편집 하나 ("프리셋: 컴프레서 보컬 고르게") | 사이드체인과 곡선은 소리가 아니라 곡의 짜임이다 |
| 사용자 프리셋 | 앱 데이터 폴더의 `InitialDAW/Presets/Effects/<형식>/<이름>.json` (효과 객체, 우회와 주석과 사이드체인과 곡선은 빼고). 편집기의 "프리셋" 메뉴: 기본 프리셋, 내 프리셋, 지금 값을 저장, 내 프리셋 지우기 | 곡과 따로, 모든 곡에서 쓴다 |
| 효과 사슬 | `Presets/Chains/<이름>.json` (효과 객체의 배열, 사이드체인과 곡선은 뺀다). 효과 슬롯의 "+" 메뉴: 효과 사슬 불러오기 (채널의 효과를 바꾼다, 편집 하나), 효과 사슬 저장 | |
| 시험 | 시험은 앱 설정을 쓰지 않으므로 프리셋 폴더를 시험 폴더로 바꿔 쓴다 (`MixerPanel::presetFolder`) | |

## 4. 확인한 것

- 기본 프리셋 31개가 모두 검사를 경고 없이 지나고 효과로 만들어져 소리를 지난다.
- `withPreset`: 압축기의 사이드체인 키, 우회, 주석이 남는다. 박 시간 딜레이 프리셋이 `timeMs` 를 지우고 `mix` 곡선은 남긴다.
- 앱: 압축기에 "보컬 고르게"를 입히면 -20 dB, 3:1 이고 실행 취소 이름에 프리셋 이름이 든다. 비율을 7 로 바꿔 "Squash" 로 저장하고 다른 프리셋을 입힌 뒤 다시 입히면 7 로 돌아온다.
  압축기와 딜레이의 사슬을 저장하고 두 효과를 지운 뒤 불러오면 같은 차례와 값으로 돌아온다. 내 프리셋 지우기. 효과 편집기 스냅숏에서 단추 배치를 확인했다.

## 5. 남은 것

- 플러그인 효과와 내장 신스의 프리셋(플러그인은 자체 프리셋과 `plugin.state` 가 있다), 프리셋을 고르기 전에 들어 보기, 채널 전체(효과, 센드, 페이더) 프리셋, 트랙 템플릿은 없다.
