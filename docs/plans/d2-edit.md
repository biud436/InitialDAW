# D2. 편집

> 작성일: 2026-10-06. 계기: 사람이 곡의 음표를 직접 찍고 고칠 수 있어야 한다. 작곡가가 음을 정한다는 점이 오디오 생성 모델과 다른 점이다.

## 1. 목표

피아노 롤에서 음표를 그리고, 옮기고, 길이와 세기를 바꾸고, 지우고, 되돌리고, 저장한다. 컨트롤러 곡선의 점을 고치고,
템포와 박자를 바꾼다. 재생 중에 고친 음이 바로 들린다. 저장한 파일은 원래 JSON 의 모르는 필드와 키 순서를 지킨다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 문서 모델 | 엔진의 `CompositionDocument` 가 JSON 트리(`juce::var`)를 들고, 편집은 트리를 고친 뒤 다시 파싱한다 | 모르는 필드, 주석, 음표마다 붙은 필드가 남는다. 파싱이 한 곳이라 앱의 편집도 `validate` 와 같은 검사를 받는다 |
| 음표 짝짓기 | 파싱한 `TrackSpec.notes[i]` 와 JSON 의 `notes[i]` 는 같은 순서다. 음표마다 원래 객체를 들고 다니다가 쓸 때 위치, 길이, 높이, 세기만 바꾼다 | 아티큘레이션, `humanize`, `comment` 가 남는다. 높이는 원래 형식(이름 `"C4"` 또는 번호)을 따른다 |
| 편집 함수 | 옮기기, 길이, 조옮김, 양자화, 붙이기, 지우기는 엔진의 순수 함수(`NoteEdits`)로 둔다 | 단위 시험으로 지키고, 앞으로 명령행과 에이전트 도구가 같은 함수를 쓴다 |
| 저장 형식 | 들여쓰기 한 칸(작곡 생성기의 `json.dump(indent=1)` 과 같다). 값이 스칼라뿐인 객체와 배열은 한 줄 | 음표 하나가 한 줄이라 diff 를 읽을 수 있다. 숫자는 되읽으면 같은 값이 되는 가장 짧은 표기, 정수는 정수로 |
| 재생 반영 | `RealtimePlayer::updateTrack` 이 연주 처리와 이벤트를 메시지 스레드에서 새로 만들어 원자 포인터로 넘긴다. 오디오 스레드는 블록 처음에 바꿔 끼우고 옛 내용은 메시지 스레드가 지운다 | 악기를 다시 읽지 않는다. 할당과 해제는 오디오 스레드 밖에서 한다 |
| 바꿔 끼울 때 | 그 트랙의 울리는 음은 끄고, 컨트롤러는 지금 위치의 값으로 다시 보낸다 (위치 옮기기와 같은 처리) | 지운 음이 계속 울리지 않는다 |
| 연주 처리의 난수 | 이미 음마다 (높이, 시작, 같은 자리의 순번) 으로 씨앗을 정한다 | 한 음을 고쳐도 다른 음의 흔들림이 바뀌지 않는다 |
| 템포와 박자 | 바꾸면 재생기를 다시 만든다 | 모든 이벤트의 샘플 위치와 강세 격자가 바뀐다. 드물게 하는 편집이다 |
| 실행 취소 | `juce::UndoManager`. 동작마다 바뀐 부분(트랙 또는 템포, 박자)의 JSON 앞뒤 사본 | 모든 편집에 같은 방식이고, 되돌린 결과가 저장 파일과 바이트 단위로 같다 |
| 파일 감시 | 앱이 저장한 직후의 수정 시각은 앱의 것으로 기록한다. 저장하지 않은 편집이 있을 때 파일이 바뀌면 묻는다 | 작곡 생성기가 파일을 다시 쓰면 앱의 편집이 사라진다 |
| 작곡 생성기와 함께 쓰기 | 생성기를 다시 돌리면 그 파일의 편집은 덮어써진다. 고친 곡은 다른 이름으로 저장해 따로 둔다 (⌘⇧S) | 생성기의 출력과 사람이 고친 판을 섞지 않는다 |
| 편집 검사 | 다시 파싱한 트랙을 재생기가 고른 악기의 프로필로 검사하고(`checkTrackAgainstInstrument`), 통과해야 실행 취소 기록에 넣는다 | 악기가 받지 않는 컨트롤러 곡선을 더하면 거절하고 상태 줄에 알린다 |
| 키 | 단축키는 모두 메인 화면의 명령으로 두고 피아노 롤의 함수를 부른다. 위, 아래 화살표는 고른 음표가 있으면 반음 조옮김, 없으면 트랙 고르기 | 메뉴와 단축키가 한 곳에 있다. 메뉴의 이름도 그때그때 바뀐다 |
| 창 없는 시험 | `--edit-test` 가 프로젝트 편집 경로를 돌리고, 피아노 롤에 마우스 사건을 만들어 보내 결과를 본다 | 창을 띄우지 않고 두 번 클릭, 끌기, 길이, 사각형 고르기, 벨로시티를 시험한다 |

## 3. 조작

피아노 롤 (격자는 왼쪽 정보 칸에서 고른다, ⌘ 를 누르고 끌면 격자를 무시한다):

| 조작 | 동작 |
|---|---|
| 빈 자리 두 번 클릭 | 음표 추가 (길이는 마지막으로 쓴 길이) |
| 음표 클릭, ⇧ 클릭 | 고르기, 고른 것에 더하거나 빼기 |
| 빈 자리 끌기 | 사각형 안의 음표 고르기 |
| 음표 끌기, ⌥ 끌기 | 옮기기 (가로는 격자, 세로는 반음), 복사해 옮기기 |
| 음표 오른쪽 끝 끌기 | 길이 |
| 음표 두 번 클릭, ⌫ | 지우기 |
| ⌘A, ⌘C, ⌘X, ⌘V, ⌘D | 모두 고르기, 복사, 잘라내기, 재생 위치에 붙이기, 바로 뒤에 복제 |
| 위, 아래 (⇧ 는 옥타브) | 고른 음표 조옮김 (고른 음표가 없으면 트랙 고르기) |
| 왼쪽, 오른쪽 | 고른 음표를 격자 한 칸 옮기기 |
| Q | 고른 음표(없으면 트랙 전체)의 시작을 격자에 맞추기 |
| 아래 칸의 벨로시티 | 막대를 끌어 세기 (고른 음표가 있으면 그것만) |
| ⌘Z, ⌘⇧Z | 실행 취소, 다시 실행 |
| ⌘S, ⌘⇧S | 저장, 다른 이름으로 저장 |

컨트롤러 곡선 (아래 칸):

| 조작 | 동작 |
|---|---|
| 빈 자리 두 번 클릭 | 점 추가 |
| 점 끌기 | 옮기기 (앞뒤 점 사이) |
| 점 두 번 클릭 | 지우기 |
| 점 오른쪽 클릭 | 다음 점까지의 모양 (직선, 계단, 지수, 부드럽게) |
| 곡선 추가 | 칸 메뉴에서 고른다 (악기가 받지 않는 컨트롤러는 거절한다) |

템포와 박자: 트랜스포트의 템포와 박자를 두 번 클릭해 고친다 (템포 점이 하나인 곡).

- 덧붙임 (2026-10-09, 마스터 키보드 없이 컴퓨터 자판으로 연주하기): 자판 연주(`TypingKeyboard`).
  아래 줄 Z X C V B N M , . / 가 C4 부터 흰건반, 그 위 줄 S D G H J L ; 가 검은건반, Q W E R T Y U I O P [ ] 가 C5 부터 흰건반,
  숫자 줄 2 3 5 6 7 9 0 = 이 검은건반이다. 고른 트랙을 엔진의 audition 으로 울리고(벨로시티 100), 누르고 떼는 것은 자판의 상태
  (`KeyPress::isKeyCurrentlyDown`)로 읽어 화음과, 같은 음을 두 자판이 누르는 것(, 와 Q)과, 누른 채 옥타브를 바꾸는 것을 다룬다.
  JUCE 8 은 한글 입력 상태에서도 자판의 영문 글자를 주므로 입력기와 상관없이 연주된다. 단축키 목록보다 먼저 묻는 자판 듣기로 붙여
  켜 있을 때는 Q(격자 맞추기)와 X(믹서)도 음을 낸다. ⌘, ⌃, ⌥ 와 함께 누른 자판과 글 입력 칸의 자판은 그대로 둔다. ⌘K 와 트랜스포트의
  단추로 켜고 끄고(설정에 남는다, 기본은 켬), ⌥↑ ⌥↓ 로 옥타브(C1~C7)를 옮긴다. 피아노 롤 건반에 자판 글자를 쓰고 누른 음을 칠한다.
  창이 뒤로 가면 누른 음을 모두 끄고, 앱의 타이머가 자판을 다시 읽어 놓친 뗌을 잡는다.
  고침 (연주할 때 누를 수 없다는 경고음이 같이 들렸다): 한글 2벌식 입력 상태에서 JUCE 8 은 키 이벤트의 글자를 돌며 자판 처리를
  부르는데, 이 이벤트에는 그 처리를 부르지 못해 macOS 가 쓰지 않은 자판으로 보고 경고음을 냈다 (음은 앱의 타이머가 자판의 상태를 읽어
  늦게 났다). macOS 에서는 `NativeKeys`(NSEvent 지역 모니터)가 자판을 JUCE 보다 먼저 물리 위치(가상 키 코드)로 받아 연주하고 그 이벤트를
  앱에 넘기지 않는다. 그래서 입력기와 상관없이 누르는 즉시 울리고 경고음과 한글 조합이 없다. ⌘, ⌃, ⌥ 와 함께 누른 자판, 글 입력 칸, 메뉴와
  대화상자, 다른 창의 자판은 그대로 넘긴다. 시험: `--edit-test` 9건(물리 위치의 배열, 받은 누름과 되풀이와 뗌, 타이머가 누른 자판을 지킴,
  배열 밖과 앱이 본 누름의 뗌은 넘김, 끄면 넘김). 실제 자판의 경고음은 저자가 확인한다
  시험: `--edit-test` 12건(배열, 화음, 같은 음 두 자판, 옥타브를 바꾼 뒤의 뗌, C 로 내리는 옥타브, 건반 글자, Q 와 X 를 가져가고 ⌘ 와
  배열 밖은 두는 것, 끄면 Q 를 단축키로), `--self-test` 가 실제 장치로 트랙을 고르고 Z 를 눌러 그 트랙의 크기가 오르는지 본다
  (「유리 회로」 -18.1 dB, 「녹슨 날개」 -15.4 dB, 「잿빛 균열」 -16.5 dB, 「눈 덮인 왕국」 -13.1 dB, 누르기 전은 0)

## 6. 남은 것

- 음 이름의 표기: 피아노 롤은 올림표로 쓴다 (F단조 곡의 Eb 가 D# 로 보인다). 곡의 조를 알면 그에 맞춘다
- 재생 중에 고치면 그 트랙의 울리는 음이 한 번 끊긴다 (바꿔 끼울 때 끈다)
- 고친 결과 곡이 재생 위치보다 짧아지면 재생이 멈춘다
- 템포 점이 여럿인 곡의 템포 편집 (템포 트랙, D7)
- 클립보드는 앱 안에만 있다 (다른 앱과 주고받지 않는다)
- 편집한 뒤 모니터 게인을 다시 재지 않는다
