# D20. 퀵 샘플러 (오디오로 악기 만들기)

> 작성일: 2026-10-23. 계기: 상용 DAW 는 오디오 한 조각을 끌어다 놓으면 건반으로 치는 악기가 된다. InitialDAW 는 샘플 악기를 SFZ 로만 받았고,
> SFZ 를 손으로 써야 했다. 소리는 라이선스가 분명한 샘플에서 나온다는 원칙에 맞게, 가진 녹음을 바로 악기로 쓰는 길이다.

## 1. 목표

오디오 파일 하나, 또는 타임라인의 클립 하나(파일의 그 구간)를 건반에 펼친 SFZ 악기로 만들고 그 악기의 트랙을 더한다. 소리의 높이를 재서
기준 건반과 센트 보정을 정해, 적은 음 높이대로 울린다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 악기 형식 | 엔진이 이미 읽는 SFZ (sfizz). 리전 하나가 0~127 건반 (`pitch_keycenter`, `tune`, 구간이면 `offset` 과 `end`) | 새 재생 경로를 만들지 않는다. 명령행 렌더와 실시간이 같다 |
| 높이 재기 | YIN (차이 함수를 누적 평균으로 나눈 값의 문턱 0.15, 포물선 보간). 앞 50 ms(어택) 뒤 2048 샘플 창을 반씩 겹쳐 64창까지, 조용한 창은 건너뛰고 분명한 창의 중앙값. 40~2000 Hz | 배음이 많은 소리에서 옥타브를 틀리지 않는다. 중앙값은 비브라토와 끝의 흔들림에 강하다 |
| 기준 건반 | 잰 높이에 가장 가까운 건반, 남은 차이는 `tune` 센트. 재지 못하면 C4. `--root` 로 정할 수 있다 | |
| 원샷 | `--one-shot` (앱: "원샷"): `pitch_keytrack=0`, `loop_mode=one_shot`. 북과 효과음 | 건반을 떼도 끝까지, 모든 건반이 같은 소리 |
| 곡에 넣기 (앱) | 곡 폴더 밖의 파일은 `samples/` 로 복사, SFZ 는 `samples/<이름>.sfz` (샘플을 상대 경로로), 악기 정의는 곡의 `"instruments"` 배열에 객체로 (`sampler.<이름>`), 새 트랙. 편집 하나 | 곡 폴더째 옮겨도 소리가 따라간다. 레지스트리 파일을 고치지 않는다 |
| 명령 | 트랙 > 오디오로 악기 만들기..., 클립 메뉴 > 이 클립으로 악기 만들기 (건반에 펼치기, 원샷). 명령행 `music-render sampler <오디오> --output <악기.sfz> [--root C3] [--one-shot]` | |

## 4. 확인한 것

- 엔진 단위 시험: 배음 여섯의 220 Hz 소리를 220.00 Hz (MIDI 57.000, 분명함 1.00)로, A4 보다 30 센트 높은 소리를 MIDI 69.30 으로 잰다. 흰 잡음은 높이가 없다.
  30 센트 높은 소리로 만든 악기가 `tune=-30` 이고, 곡 안의 정의로 E5 를 치면 659.26 Hz (기대 659.26)로 울린다.
- 명령행: 330 Hz 사인파를 E4 (기준 건반 64, -1.8 센트)로 재고, `--root C3 --one-shot` 은 재지 않으며, 모르는 음 이름은 사용법 오류 (종료 2), 만든 SFZ 를 곡 안의 정의로 렌더링한다.
- 앱 `--edit-test` 8건: 곡 폴더 밖의 "Bell Tone.wav" (C4 사인파)가 `samples/` 로 복사되고 `samples/bell-tone.sfz` 의 `pitch_keycenter=60`, `sample=Bell Tone.wav`,
  곡에 `sampler.bell-tone` 정의와 "Bell Tone" 트랙, 같은 파일의 0.25~0.75초 구간의 원샷은 `sampler.bell-tone-2` (`offset=11025`, `end=33074`), 실행 취소로 처음 곡과 같다.
- 시험을 쓰며 앱이 지금 문서의 뿌리 객체에 `instruments` 를 직접 써서 실행 취소가 앞 상태를 잃었다 (`documentRoot()` 는 사본이 아니다). 사본에 쓰게 고쳤다.

## 5. 남은 것

- 여러 샘플을 건반 범위나 벨로시티 층으로 나누는 멀티 샘플 악기, 루프 지점 찾기 (지금은 소리가 끝나면 끝난다), 샘플 편집 화면은 없다.
- 실제 악기 녹음으로 높이 재기를 저자가 확인한다 (시험은 만든 소리).
