# D5. 녹음

> 작성일: 2026-10-12. 계기: 직접 연주해 넣는 길이 없었다. 앱은 음을 그리고
> 코드와 스케일을 넣을 수 있지만, 건반(MIDI 장치)이나 컴퓨터 자판으로 친 연주를 곡에 남기는 길이 없었다. 반복 구간은 곡 JSON 에만 있고
> 앱에서 되풀이해 들을 수도, 고칠 수도 없었다.

## 1. 목표

고른 트랙에 MIDI 장치나 컴퓨터 자판으로 친 음을 녹음한다. 메트로놈과 카운트인을 듣고 들어가고, 반복 구간을 켜면 그 구간이 되풀이되며
친 음이 쌓인다 (오버더브). 녹음한 음은 편집 하나(실행 취소 한 번)로 트랙에 들어가고, 저장하면 곡 JSON 의 음표가 된다.
반복 구간(`metadata.loop`)은 눈금자에 보이고 끌어서 고친다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 엔진 먼저 | 반복 재생, 메트로놈, 카운트인은 `RealtimePlayer` 에, 녹음기는 `midi/MidiRecorder` 에 둔다. 앱은 장치(MIDI 입력)와 화면만 맡는다 | 엔진에 없는 것을 앱에서 흉내 내지 않는다. 녹음기는 스레드가 없는 순수한 계산이라 창 없이 시험한다 |
| 반복 재생 | 재생기의 반복 구간(샘플)에 닿으면 블록을 나눠 끝 샘플에서 시작 샘플로 돌아간다. 돌아갈 때 울리는 음을 끄고 컨트롤러를 그 자리의 값으로 다시 보낸다 (위치 옮기기와 같은 길) | 되돌아간 뒤의 소리가 그 자리에서 새로 시작한 재생과 같다 (시험으로 지킨다) |
| 메트로놈 | 재생기가 박마다 짧은 사인파(마디 첫 박 1760 Hz, 나머지 1320 Hz, 25 ms)를 모니터 게인과 리미터 뒤에 더한다. 내보내기에는 없다. 템포 지도를 따르므로 루바토에서도 박에 맞는다 | 곡의 소리를 지나지 않아 마스터 효과와 음량 맞춤에 영향이 없다 |
| 카운트인 | 지금 위치 앞의 1~2마디 동안 메트로놈만 울린 뒤 재생(과 녹음)을 시작한다. 그 동안 `isPlaying()` 은 false, 위치는 그대로다. 카운트인의 박은 템포 지도를 0 앞으로 늘여 센다 | 곡의 처음(0박)에서도 카운트인이 된다 |
| 녹음기 | `MidiRecorder` 는 박 단위로 음 켜기와 끄기, 컨트롤러를 받아 음표와 곡선 점으로 만든다. 옵션: 시작을 격자에 맞추기(길이는 그대로), 펀치(그 박 구간에서 시작한 음만), 반복 끝 박(되돌아간 뒤에 뗀 음은 거기서 끝난다). 녹음한 음은 `humanize: false` | 사람이 친 타이밍을 엔진의 휴머나이즈가 다시 흔들지 않는다 |
| 시각 | MIDI 콜백(MIDI 스레드)에서 오디오 콜백이 마지막으로 쓴 블록의 시작 샘플과 시각으로 지금 샘플을 어림한다 (`AudioEngine::estimatedPosition`). 자판 연주는 메시지 스레드의 그 순간 위치 | 메시지 스레드의 지연이 녹음 타이밍에 들어가지 않는다 |
| 듣기 | MIDI 입력의 음은 녹음하지 않을 때도 고른 트랙의 악기로 들린다 (자판 연주와 같은 `audition` 길). 페달과 모듈레이션은 `auditionController` 로 보낸다 | 치면서 소리를 고른다 |
| 반복 구간 편집 | 눈금자(트랙 보기, 피아노 롤)에 띠로 보이고, ⌥ 끌기로 새로 정하고, 띠의 양 끝을 끌어 고친다 (박에 맞추고, 축소하면 마디에). 편집 메뉴: 고른 음표 구간을 반복 구간으로, 반복 구간 지우기. 곡 JSON 의 `metadata.loop` 를 바꾸는 편집 하나 | 내보내기의 "반복 구간" 과 같은 값이다 |
| 단축키 | ⌥R 녹음, ⌥L 반복, ⌥M 메트로놈. 카운트인(없음, 1마디, 2마디), 펀치, 녹음할 때 격자 맞추기는 재생 메뉴 | 자판 연주가 켜져 있으면 글자는 음이다. ⌥ 와 함께 누른 자판은 단축키로 남는다 |
| 녹음 흐름 | 멈춘 채 ⌥R: 카운트인 뒤 재생 위치부터 고른 트랙에 녹음. 재생 중 ⌥R: 바로 녹음. 다시 ⌥R: 녹음을 끝내고(편집 하나) 재생은 이어진다. 정지: 녹음을 끝내고 멈춘다. 반복이 켜져 있으면 되풀이하며 쌓인다 | |
| MIDI 입력 장치 | 설정 메뉴에서 장치마다 켜고 끈다 (기본 모두 켬). 2초마다 새 장치를 찾는다. 켠 장치 목록은 앱 설정에 남는다 | 꽂으면 바로 쓴다 |
| 창 없는 시험 | 엔진 단위 시험(반복, 메트로놈, 카운트인, 녹음기), `--edit-test` 의 녹음기와 반복 구간 편집(눈금자 끌기, 메뉴), `--self-test` 의 실제 장치 녹음(자판 Z 를 0.3초 눌러 음표 하나가 들어가는지) | |

## 4. 확인한 것

- 엔진 단위 시험 131건(검사 3550): 반복 구간 [2, 4)박을 켜고 처음부터 4초 재생하면 되돌아간 뒤 2초가 2~4초의 오프라인 렌더와 1e-5 안에서 같다 (되돌아갈 때 울리는 음이 없을 때).
  메트로놈은 3/4 에서 박마다 소리가 나고 사이는 조용하며 마디 첫 박의 주파수가 높다. 카운트인 1마디(2초)는 소리 없이 네 번 울린 뒤 정확히 2초째 샘플부터
  곡이 그 자리의 오프라인 렌더와 같다. 녹음기: 켜고 뗀 음의 박과 길이, 누른 채 끝낸 음, 다시 누른 음, 격자 맞추기, 펀치, 반복 끝, 페달의 step 점과 같은 값 솎기.
- 앱 `--edit-test` 149건: 녹음기의 결과를 편집 하나로 트랙에 넣고(음표는 시작 순서, 페달 점은 있던 곡선에 더한다) 실행 취소로 돌아온다. 반복 구간 편집은 metadata 의
  다른 필드를 지키고 실행 취소로 돌아오며, 반복 구간을 지우면 반복이 꺼진다. 트랙 보기의 눈금자 ⌥ 끌기로 [4, 12) 를 정하고 띠의 끝을 끌어 [4, 16) 으로, 피아노 롤의
  눈금자로 [8, 20) 을 정했다. 눈금자를 그냥 누르면 재생 위치만 옮긴다. 재생기가 없으면 녹음을 시작하지 않는다.
- 앱 `--self-test` (「칼날 질주」, 44.1 kHz, 512 샘플): 카운트인 없이 녹음을 켜고 MIDI 입력의 길로 음을 0.3초 누르면 고른 트랙에 음표 하나가 들어갔다
  (시작은 재생 위치와 같고 길이 0.293초). 자판 연주로는 재지 못한다: 창 없는 시험에서는 앱의 타이머가 실제 자판을 읽어 바로 떼기 때문이다.
- 스냅숏(`--snapshot`, 「칼날 질주」): 녹음 단추, 눈금자의 반복 띠(5마디부터), 반복과 메트로놈 단추를 확인했다.

## 5. 남은 것

- MIDI 입력의 시각 어림은 블록 하나(512샘플, 11 ms) 안이다. 장치와 출력의 지연을 빼는 보정값은 아직 없다.
- 녹음은 음표와 컨트롤러 곡선만 남긴다. 아티큘레이션은 트랙 기본값이다.
- 오디오 트랙(소리 녹음)은 D8 이다.
