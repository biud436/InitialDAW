# D26. MIDI 배우기 (하드웨어 컨트롤러 잇기)

> 작성일: 2026-10-23. 계기: 상용 DAW 는 MIDI 컨트롤러의 노브와 페이더를 화면의 컨트롤에 묶는다 (MIDI 배우기). 마우스로 한 번에 하나씩
> 움직이던 믹스를 손으로 여러 개 함께 움직이고, 곡선 쓰기(D19)와 함께 쓰면 연주하듯 오토메이션을 적는다.

## 1. 목표

보기 > MIDI 배우기 (⌘⇧L)를 켜면 믹서 위에 덮개가 씌워진다. 페이더, 밸런스, 뮤트, 솔로, VCA 페이더와 뮤트, 열린 효과의 숫자 매개변수를 누르고
컨트롤러를 움직이면 그 CC 가 묶인다. 묶인 컨트롤러는 그 컨트롤을 손으로 움직이는 것과 같다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 묶음의 자리 | 앱 설정 (`midiLearn`: MIDI 채널, CC, 자리의 글). 자리는 채널의 순서로 가리킨다 ("track:0/fader", "bus:1/mute", "master/fader", "vca:0/fader", "track:2/effect:1/cutoffHz") | 컨트롤러 배치는 곡이 아니라 작업대의 것이다. 순서로 가리키면 어느 곡에서나 "1번 페이더가 1번 트랙" |
| 배우기 | 덮개가 컨트롤마다 테두리를 그리고 묶인 것에 "CC n" (채널 1 이 아니면 "/채널"). 누르면 그 자리를 고르고, 다음에 온 CC 를 묶는다 (같은 CC 나 같은 자리의 앞 묶음은 지운다). 오른쪽 클릭은 묶음 지우기. 배우는 동안 받은 CC 는 트랙으로 보내지 않는다 | |
| 움직이기 | 슬라이더(페이더, 밸런스, VCA 페이더): 처음 값에서 그 슬라이더의 끌기를 시작하고 값을 바꾼다. 0.4초 조용하면 끌기를 끝낸다. 그래서 끄는 동안 미리 듣고 놓을 때 편집 하나이며, 곡선 쓰기 모드에서 재생 중이면 곡선으로 적힌다 | 손으로 끄는 길을 그대로 탄다 (새 편집 길을 만들지 않는다) |
| 값 | 페이더는 믹서의 페이더 눈금(위치에서 dB), 밸런스는 -1..1 (64 는 가운데), 효과 매개변수는 범위 안에서 직선, 로그 매개변수(주파수, 시간)는 로그, 켜기와 끄기는 반에서, 선택지는 가까운 것. 효과는 곡 JSON 으로 미리 듣고 놓을 때 편집 하나 | 노브 반 바퀴가 주파수의 가운데 (20 Hz~20 kHz 에서 632 Hz) |
| 단추 | 뮤트와 솔로는 값이 64 를 넘어 오를 때 한 번 누른다 | 누르면 127, 떼면 0 을 보내는 단추와 번갈아 보내는 단추 모두 |
| 묶인 CC | 묶인 CC 는 트랙으로 보내지 않는다 (고른 트랙의 컨트롤러로 쓰지 않는다) | |

## 4. 확인한 것

- 덮개가 트랙 페이더를 내놓고, 그 가운데를 누르면 그 자리를 고르고, 다음 CC 21 이 묶인다.
- CC 21 을 64, 100 으로 움직이면 미리 듣기만 하고 곡은 그대로, 놓으면 페이더가 페이더 눈금의 100/127 자리 dB 로 편집 하나.
- 뮤트에 묶은 CC 22: 127 에서 한 번 바뀌고 0 에서는 그대로, 다시 127 에서 돌아온다.
- 열린 필터의 차단 주파수를 덮개가 내놓고, MIDI 채널 2 의 CC 74 를 묶으면 127 이 20 kHz, 64 가 로그 눈금의 자리 (1% 안). 채널 1 의 CC 74 는 묶이지 않았다.
- 앱 설정의 글로 묶음 셋이 그대로 돌아온다. 시험을 쓰며 설정을 읽는 코드가 잠깐 있는 JSON 값의 배열을 가리키던 것을 찾아 고쳤다.
- 실제 컨트롤러로는 저자가 확인한다 (창 없는 시험은 메시지를 직접 넣는다).

## 5. 남은 것

- 고른 트랙을 따르는 자리("고른 트랙의 페이더"), 재생과 녹음 단추, 컨트롤러로 값을 되돌려 보내기(모터 페이더, LED), 상대값 노브(엔코더), 14비트 CC, 플러그인과 내장 신스의 매개변수는 없다.
