# D17. 트랙 출력(서브그룹)과 폴더

> 작성일: 2026-10-23. 계기: 상용 DAW 와 견준 빈자리(D8 1절)의 "트랙 폴더와 묶음". 트랙은 늘 마스터로 나갔고(버스는 센드로만),
> 트랙이 많은 곡(「새벽 세 시」 11 트랙)을 갈래로 묶어 볼 길이 없었다.

## 1. 목표

트랙의 소리를 버스로 보내 버스가 묶음의 페이더와 효과가 되게 한다. 트랙 보기에서 트랙을 폴더로 묶어 접고 펴고, 폴더를 같은 이름의 버스로 묶는다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 출력 | 트랙의 `"output": "<버스>"` (없으면 마스터). 페이더 뒤의 소리가 마스터 대신 그 버스로 간다. 센드는 그대로다. 버스는 마스터로만 나간다 (버스에서 버스로는 없다) | 서브그룹. 버스의 효과, 페이더, 곡선, 뮤트가 묶음 전체에 걸린다 |
| 검사 | 없는 버스 이름은 오류 (가까운 이름을 알린다) | |
| 렌더와 재생 | 오프라인과 실시간 모두 트랙 합치기에서 그 버스의 입력으로 더한다. 출력이 바뀌면 재생기를 다시 만든다 | 실시간이 오프라인과 같다 (시험) |
| 버스 이름 바꾸기와 지우기 | 센드처럼 출력도 따라간다. 지운 버스로 나가던 트랙은 마스터로 | |
| 폴더 | 트랙의 `"folder": "<이름>"` (소리에 쓰지 않는다). 같은 이름이 이어진 트랙들 위에 머리 줄 하나 (트랙 수와 모두 같은 버스로 나가면 그 버스). 머리 줄을 누르면 접고 편다 (화면 상태, 곡에 쓰지 않는다) | 곡 JSON 은 트랙 목록 그대로, 화면만 묶는다 |
| 명령 | 트랙 머리 메뉴의 "출력" (마스터와 버스들)과 "폴더" (새 폴더로 묶기, 있는 폴더에 넣기, 빼기). 트랙 보기의 고른 구간에 그 트랙이 들면 구간의 트랙 모두에. 폴더 머리 메뉴: 접기와 펴기, 이름 바꾸기, 모두 뮤트, 같은 이름의 버스로 묶기(없으면 버스를 만든다), 버스 묶음 풀기, 폴더 풀기. 모두 편집 하나 | |
| 믹서 | 버스로 나가는 트랙의 스트립에 "→ 버스" | |

## 4. 확인한 것

- 엔진 단위 시험: 두 사인파 트랙을 -12 dB 버스로 보내면 마스터가 마스터로 바로 보낸 곡의 0.2512 배 (-12 dB), 실시간과 오프라인이 1e-5 안. 없는 버스는 검사 오류.
- 앱 `--edit-test` 11건: 트랙을 버스로, 두 트랙을 폴더로, 머리 줄이 트랙 위에, 접으면 두 트랙이 감춰지고 다음 트랙이 올라온다, 펴기, 폴더를 버스로 묶기(버스를 만든다),
  버스 이름을 바꾸면 출력도, 버스를 지우면 마스터로, 폴더 이름 바꾸기, 폴더 풀기, 실행 취소.
- 스냅숏: 「새벽 세 시」 사본의 드럼 셋을 Drums 폴더(Drums 버스로), 기타 둘을 Guitars 폴더로.

## 5. 남은 것

- VCA (합치지 않고 여러 페이더를 함께 움직이는 묶음), 버스에서 버스로의 출력은 없다.
