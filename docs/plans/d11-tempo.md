# D11. 템포와 박자

> 작성일: 2026-10-22. 계기: 상용 DAW 와 견준 빈자리 표(D8 1절)의 템포 칸. 템포 점은 템포 대화상자(곡 전체의 한 값)나 곡 JSON 으로만
> 고칠 수 있었고, 박자는 곡 전체에 하나다.

## 1. 목표

템포 지도를 앱에서 그리고 (계단과 램프), 곡 중간에 박자를 바꾼다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 템포 곡선 | 피아노 롤 아래 칸의 상자에 늘 "템포 (곡 전체)" 가 있다. 템포 점의 `ramp` 는 직선, 아니면 계단으로 그리고 모양 메뉴는 이 둘만. 새 점은 앞 점의 모양을 따른다. 첫 점은 늘 0 박이고 지우지 않는다. 같은 박의 점은 뒤의 것 | 엔진의 템포 점(`{beat, bpm, ramp}`)과 같다 |
| 눈금 | 곡의 가장 느린 템포와 빠른 템포에서 40 BPM 바깥까지 (10 단위). 편집하면 눈금이 새 템포에 맞춰진다 | 20~300 의 고정 눈금에서는 70~96 의 변화가 거의 평평했다 |
| 반영 | 템포 편집은 편집 하나(`editTempo`)이고 재생기를 다시 만든다 | 템포는 모든 소리의 시각을 바꾼다 |
| 박자 바꾸기 | 최상위 `meterChanges`: `[{ "beat": 64, "timeSignature": [3, 4] }]`. `timeSignature` 는 곡의 처음 박자. 바꾸는 박은 앞 박자의 마디 줄이어야 한다 (검사 오류에 앞뒤 마디 줄을 알린다) | 음표와 마커처럼 박으로 적어 마디 번호가 앞의 박자에 매이지 않는다 |
| 박자 지도 | `MeterMap`: 박자마다 시작 박, 첫 마디 번호, 마디 길이. 박에서 마디와 마디 안의 박으로, 마디에서 박으로, 마디 줄 목록. 0 박 앞은 처음 박자로 거꾸로 센다 (카운트인) | 마디를 세는 모든 곳(눈금자, 맞추기, 명령행 `--bars`, 내보내기의 마디 구간, 트랜스포트, 메트로놈)이 같은 지도를 쓴다 |
| 마디 넣기 | 넣는 마디는 넣는 자리 앞의 박자로. 그 자리의 박자 바꾸기는 뒤로 밀린다. 지우는 구간 안의 박자 바꾸기는 마지막 것이 구간 처음으로 옮겨 뒤의 음악이 제 박자를 지킨다 (처음에서 지우면 곡의 처음 박자가 된다) | 마디 줄에서 벗어나지 않는다 |
| 메트로놈 | 4분음표마다 치고, 마디의 첫 박(박자 지도의 마디 줄)에 높은 소리. 카운트인은 시작 자리의 박자로 마디를 센다 | 6/8 이 4분음표 여섯마다 강세를 넣던 것을 고쳤다 |
| 앱 | 편집 메뉴의 "재생 위치의 마디부터 박자" 에서 2/4 ~ 12/8 를 고르고, 같은 마디의 바꾸기를 지운다. 곡의 처음이면 처음 박자를 바꾼다. 눈금자에 바뀌는 자리의 박자를 적는다 | |

## 3. 체크리스트

- [x] 앱: 템포 곡선 (`AutomationTargets` 의 `tempoTarget`, `tempoLane`, `tempoPoints`), 첫 점 지키기, 모양 메뉴
- [x] 앱 시험: `--edit-test` (늘 있는 템포 칸, 눈금, 점 넣기, 끌기, 첫 점 지키기)
- [x] 엔진: 곡 중간의 박자 바꾸기 (`meterChanges`, `timing/MeterMap`, 강세 무늬, 메트로놈과 카운트인, 플러그인의 플레이헤드, MIDI 내보내기와 가져오기, 명령행의 마디, 편곡 함수)
- [x] 앱: 박자 지도의 눈금자(바뀌는 자리의 박자 표시)와 격자, 마디 맞추기, 트랜스포트의 마디와 박자, 편집 메뉴의 "재생 위치의 마디부터 박자", 내보내기의 마디 구간
- [ ] 트랙 병렬 처리의 잰 값 (실시간 재생기의 일꾼 풀)

## 4. 확인한 것

- 앱 `--edit-test` 290건 가운데 템포 5건: 120 BPM 곡의 눈금이 80~160, 4박에 두 번 눌러 140 BPM 계단 점, 끌어서 100 BPM, 첫 점은 지우지 않는다.
- 스냅숏(`--lane tempo`): 76, 96(램프), 70 BPM 의 곡에서 재생 위치의 96.0 BPM.
- 엔진 단위 시험 5건 더: 4/4, 3/4, 6/8 의 박자 지도(마디 번호, 마디 시작, 마디 안의 박, 가까운 마디 줄, 마디 줄 목록, 0 박 앞), 검사(마디 줄이 아닌 자리,
  2의 거듭제곱이 아닌 단위, 차례), 7/8 의 마디 시작, 시간 넣기와 지우기가 박자 바꾸기를 옮기는 것, MIDI 내보내기와 가져오기의 5/8 과 4/4,
  메트로놈 강세가 4/4 한 마디 뒤 3/4 와 6/8 에서 0, 4, 7, 10 박.
- 앱 `--edit-test` 296건 가운데 박자 6건: 재생 위치의 마디(8박)부터 3/4, 그 뒤 마디와 박의 이름, 같은 마디에서 다른 박자로 바꾸기, 지우기, 처음 박자, 실행 취소.
- 스냅숏: 4/4, 3/4(5마디), 6/8(9마디), 4/4(13마디)의 눈금자와 격자, 트랜스포트의 8.2 와 박자 3/4.
