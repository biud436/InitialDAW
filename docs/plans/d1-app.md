# D1. 앱 뼈대와 실시간 재생

> 작성일: 2026-10-05. 계기: 음악 엔진 위에 DAW 를 만든다. 음악 엔진을
> 이 저장소로 옮기고, 그 위에 사람이 쓰는 첫 화면을 올린다.

## 1. 목표

Composition JSON 을 열어 곡 전체를 보고, 아무 위치에서나 실시간으로 들을 수 있다. 소리는 엔진의 오프라인 렌더와
같다. 편집은 다음 단계(D2)다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 앱 틀 | JUCE 8 GUI 앱 (`juce_add_gui_app`), 엔진의 핵심 라이브러리를 링크 | 오디오 장치, 플러그인 편집기 창, MIDI 입력까지 한 틀에서 된다. JUCE 모듈은 핵심 라이브러리에 한 번만 컴파일한다 |
| 재생 | 엔진의 `RealtimePlayer` | 오프라인과 같은 트랙 사슬. 앱에 따로 오디오 그래프를 두지 않는다 |
| 재생기 바꾸기 | 메시지 스레드에서 만들어(뒤 스레드) 스핀 락 안에서 포인터만 바꾼다 | 오디오 콜백은 잠금을 시도만 하고, 못 잡으면 그 블록을 비운다 |
| 플러그인 악기 | 메시지 스레드에서 만든다 | 일부 형식이 메시지 스레드를 요구한다. SFZ 와 내장 신스는 뒤 스레드에서 |
| 음량 | 모니터 게인(재생 전용)을 끝의 리미터 앞에 둔다. 곡을 열면 0 dB 로 두고, 뒤에서 파일 없이 렌더링해 잰 정규화 게인(내보내기와 같은 값)으로 맞춘다 | 목표 LUFS 정규화는 곡 전체를 재야 해서 실시간으로 못 한다. 처음에는 "목표 + 28 dB"로 어림했는데 신스 곡(날 믹스 -15 LUFS)에서 13 dB 크게 나와 2026-10-06 측정으로 바꿨다. 사람이 슬라이더를 움직이면 잰 값으로 덮지 않는다. 플러그인 악기가 있는 곡은 재지 않는다 |
| 화면 글꼴 | macOS 는 Apple SD Gothic Neo | 한글과 라틴 글자를 한 글꼴로 |
| 검증 | `--snapshot`(창 없이 PNG), `--self-test`(장치를 열고 -60 dB 로 3초) | 창을 띄우지 않고 화면과 재생 경로를 시험한다 |

## 3. 화면

```text
┌ 트랜스포트: 곡 이름 │ 처음으로 재생 │ 마디.박  시각 │ 템포 박자 │ 모니터 게인 │ 상태  CPU ┐
├ 트랙 머리 (이름, 악기, M, S, 레벨) │ 눈금자, 트랙마다 음표와 다이내믹스 곡선, 재생 위치     ┤
├────────────────────────── 나누는 막대 ───────────────────────────────────────┤
└ 고른 트랙의 정보와 건반 │ 눈금자, 음높이 격자의 음표, 컨트롤러 곡선(탭으로 고른다)           ┘
```

트랙 보기와 피아노 롤은 왼쪽 열의 너비(230)가 같아 가로축이 맞는다. 확대, 스크롤, 재생 위치를 함께 쓴다.

## 4. 조작

| 조작 | 동작 |
|---|---|
| 스페이스 | 재생과 정지 |
| 리턴, 홈 | 처음으로 |
| ⌘O, ⌘R | 열기, 다시 불러오기 |
| ⌘=, ⌘-, ⌘0 | 확대, 축소, 곡 전체 보기 |
| 위, 아래 화살표 | 위 트랙, 아래 트랙 |
| ⌘, | 오디오 장치 |
| 눈금자 클릭과 끌기 | 재생 위치 |
| 휠, 시프트 휠, ⌘ 휠, 핀치 | 세로 스크롤, 가로 스크롤, 확대 |
| 피아노 롤에서 ⌥ 휠 | 건반 높이 |
| M, S | 뮤트, 솔로 (재생 중에 바로) |

파일이 바뀌면 1초 안에 다시 불러온다 (파일 메뉴에서 끌 수 있다). 재생 중이면 같은 위치에서 이어 재생한다.

## 5. 체크리스트

- [x] 엔진을 Initial2D 에서 이력째 옮기고 최상위 CMake 와 `build.sh` 로 묶기
- [x] 엔진: 트랙 사슬 공유, 실시간 재생기, 실시간 악기 모드, 내장 신스의 음별 난수, `realtime` 명령
- [x] 앱: 창, 메뉴(파일, 재생, 보기, 설정), 단축키, 최근 프로젝트, 설정 저장(오디오 장치, 자동 다시 불러오기)
- [x] 트랜스포트, 트랙 보기, 피아노 롤 보기, 컨트롤러 곡선 탭
- [x] 뒤 스레드에서 재생기 만들기와 진행 표시, 다시 불러와도 앞의 결과는 버린다(세대 번호)
- [x] 실시간 뮤트와 솔로, 트랙 레벨 미터, 재생 중 화면 따라가기
- [x] 장치의 샘플레이트가 바뀌면 재생기를 다시 만든다
- [x] `--snapshot` 과 CTest `app_snapshot`, `--self-test`
- [x] 모니터 게인을 뒤에서 잰 음량으로 맞추기 (`--self-test --loudness` 로 확인: 「푸른 신호」 +3.5 dB, 내보내기의 정규화 +3.72 dB)
