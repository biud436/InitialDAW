# D29. 대역별 압축, 트랜지언트, 디에서

> 작성일: 2026-10-23. 계기: 상용 DAW 의 기본 효과에는 마스터링의 멀티밴드 컴프레서, 북의 어택과 울림을 고치는 트랜지언트 셰이퍼,
> 보컬의 치찰음을 줄이는 디에서가 있다. 지금 효과(EQ, 컴프레서, 리미터 등) 곁에 엔진 효과로 더한다.

## 1. 목표

- `multiband`: 두 주파수에서 나눈 세 대역을 따로 압축하고 대역마다 게인을 더한다. 압축하지 않으면 크기가 평평하다.
- `transient`: 어택(소리가 차오르는 첫 몇 ms)과 서스테인(잦아드는 울림)을 따로 키우거나 줄인다. 고른 소리는 그대로.
- `deesser`: 나눔 주파수 위 대역이 스레숄드를 넘을 때 그 대역만 줄인다.
- 기본 프리셋, 화면의 이름과 설명.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 나누기 | 링크위츠-라일리 4차 (버터워스 2차 두 단). 세 대역은 낮은 쪽을 둘째 나누기의 낮은 쪽과 높은 쪽 합(올패스)에 지나게 해 위상을 맞춘다 | 대역을 다시 더하면 크기가 평평하다 (잰 값 0.000 dB) |
| 멀티밴드 매개변수 | 평평한 표: `lowHz`, `highHz` (두 배 넘게 떨어져야 한다), 대역마다 `<대역>ThresholdDb`, `<대역>Ratio`, `<대역>GainDb`, 함께 쓰는 `attackMs`, `releaseMs`, `kneeDb`. 검출은 좌우를 묶은 피크, 게인 계산은 컴프레서와 같은 니 | 앱의 효과 매개변수 화면이 표로 그린다 |
| 트랜지언트 | 5 ms RMS 를 네 엔벨로프로 따른다: 어택 1 ms 와 25 ms (둘 다 릴리스 20 ms)의 차이가 어택, 릴리스 300 ms 와 20 ms (둘 다 어택 1 ms)의 차이가 서스테인. 차이 1~12 dB 에서 0 에서 끝까지 `attackDb`, `sustainDb` 를 건다, `outputDb` | 피크를 따르면 잡음의 들쭉날쭉이 어택으로 보였고 (꼬리가 +6.5 dB), 어택 엔벨로프의 릴리스가 길면 꼬리에서 차이가 남았다 (+1.5 dB) |
| 디에서 | `frequencyHz` 에서 나눈 높은 대역의 피크(10 ms 로 내려온다)를 비율 4 로 `rangeDb` 까지 (어택 0.5 ms, 릴리스 60 ms) | 순간 피크만 보면 사인파의 영점마다 놓아 덜 줄었다 |
| 프리셋 | 마스터 대역별 묶기, 저음 고르게, 드럼 어택 살리기, 드럼 울림 줄이기, 울림 길게, 보컬 치찰음, 밝은 치찰음 (모두 38개) | |

## 4. 확인한 것

- 멀티밴드: 압축하지 않으면 40 Hz~15 kHz 사인파가 0.000 dB 안. 큰 80 Hz(-6 dBFS)와 작은 10 kHz 에 저역 -30 dB, 4:1, 고역 게인 +6 이면 80 Hz -15.6 dB, 10 kHz +5.99 dB.
- 트랜지언트 (잡음이 바로 차올라 50 ms 로 잦아드는 북): 어택 +12 는 머리 5 ms 가 +12.0 dB, 0.12~0.25초 꼬리가 +0.0 dB. 서스테인 -12 는 꼬리 -12.0 dB, 머리 -1.2 dB. 300 Hz 사인파는 0.1 dB 안.
- 디에서 (나눔 5 kHz, -30 dB, 최대 8 dB): -10 dBFS 의 10 kHz 가 -7.53 dB, 500 Hz 는 0.00 dB, 작은 10 kHz(-46 dBFS)는 0.2 dB 안.

## 5. 남은 것

- 대역마다의 게인 감소 미터, 대역 솔로(그 대역만 듣기), 멀티밴드의 곡선(오토메이션)은 없다.
- 디에서의 키 신호 듣기(치찰음만 듣기)는 없다.
