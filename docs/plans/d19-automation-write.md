# D19. 곡선 쓰기 (오토메이션 녹음)

> 작성일: 2026-10-23. 계기: 곡선은 그릴 수만 있었다 (D10). 상용 DAW 는 재생하며 페이더를 움직이면 그 움직임을 곡선으로 적는다.

## 1. 목표

곡선 쓰기를 켜고 재생하며 믹서의 페이더와 밸런스를 움직이면, 움직인 동안의 값이 그 채널의 곡선이 된다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 켜기 | 보기 메뉴의 "곡선 쓰기" (⌥A). 켜면 곡선이 있는 페이더와 밸런스도 끌 수 있다 | 곡선이 있는 값은 평소에 끌 수 없다 (D10) |
| 모으기 | 재생 중에 페이더나 밸런스를 끄는 동안 (재생기의 곡 위치의 박, 값)을 모은다. 같은 박이면 값을 바꾼다 (멈췄거나 반복으로 돌아왔을 때) | 손으로 움직인 대로 |
| 듣기 | 끄는 동안은 그 채널의 곡선을 잠시 빼고 손의 값을 들려준다 (미리 듣기로 재생기에 반영) | 쓰는 소리를 바로 듣는다 |
| 적기 | 손을 떼면 편집 하나: [첫 박, 끝 박] 의 곡선을 모은 점으로 바꾼다 (1/16 박 안이고 거의 같은 값의 점은 줄인다). 앞은 원래 곡선(없으면 0 박에 원래 값을 붙드는 계단 점), 끝 박 바로 뒤는 원래 곡선이나 원래 값으로 돌아간다 | 터치 방식: 손을 댄 동안만 바뀐다 |
| 채널 | 트랙, 버스, 마스터의 `mixer.automation` 의 `gainDb` 와 `pan` | 곡선의 자리는 D10 과 같다 |

## 4. 확인한 것

- 앱 `--edit-test` 6건: 4 박부터 1/4 박마다 페이더를 올린 곡선이 0 박에 원래 값의 점, 2 박은 원래 값, 5.5 박은 원래보다 0.5 dB 넘게 크고 5.9 박이 4.6 박보다 크다,
  8 박은 원래 값, 편집 하나, 곡선이 있어도 끌 수 있다, 실행 취소.
- 실제 재생 중의 쓰기는 저자가 확인한다 (창 없는 시험은 재생 박을 흉내 낸다).

## 5. 남은 것

- 센드 크기와 효과 매개변수의 쓰기, 래치 방식(손을 떼도 마지막 값을 지킨다), 외부 MIDI 컨트롤러로 쓰기는 없다.
