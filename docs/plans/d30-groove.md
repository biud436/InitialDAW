# D30. 그루브 템플릿

> 작성일: 2026-10-23. 계기: 상용 DAW 는 연주(음표나 오디오)에서 박의 어긋남과 강세를 뽑아 그루브로 두고, 다른 트랙의 음표와 오디오를
> 그 느낌으로 맞춘다 (그루브 퀀타이즈). 기본 스윙(16분음표 54~66% 등)도 둔다. D12 의 음표 다듬기와 D27 의 워프 마커 위에 올린다.

## 1. 목표

- 그루브: 격자 칸마다 어긋남(박)과 세기 배수를 한 주기 동안 적은 것.
- 음표에서 뽑기 (고른 음표나 트랙), 오디오 클립의 어택에서 뽑기 (어긋남과 크기).
- 입히기: 음표(시간과 세기를 따로 세기로), 오디오 클립(워프 마커로 어택을 그루브 자리에).
- 기본 그루브와 내 그루브 (앱 데이터 폴더), 명령행.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 형식 | `{ "name", "grid", "steps": [ { "offset", "velocity" } ] }`. 주기는 칸 수 x 격자이고 곡의 0 박에서 시작한다. 어긋남은 한 칸 안 | 사람이 읽고 고친다. 엔진 `composition/Groove` |
| 기본 그루브 | 16분음표 스윙 54, 58, 62, 66%, 8분음표 스윙 55, 60, 67% (짝의 둘째 음이 짝 길이의 몇 % 에 오는가), 느긋하게(엇박이 늦고 여리다), 서두르게(엇박이 이르다), 2, 4박 강세 | 드럼 머신의 스윙 값 |
| 음표에서 | 구간 안에서 시작하는 음을 가까운 격자 칸에 모아 칸마다 어긋남의 중앙값과 세기 평균 / 전체 평균. 앱은 고른 음표가 시작하는 마디부터 지금 격자로 한 마디 | |
| 어택에서 | 클립의 어택(`detectOnsets`)의 곡의 박(늘인 클립이면 늘인 자리)과 그 뒤 30 ms 의 피크(`onsetLevelsDb`). 세기 배수는 10^(크기 차이/40) (세기의 제곱이 크기라고 본다). 앱은 16분음표 격자로 한 마디 | |
| 음표에 입히기 | `applyGroove`: 시작을 가까운 칸의 자리(칸 + 어긋남)로 timing 만큼, 세기를 그 칸의 배수 쪽으로 velocity 만큼. 길이는 그대로. 앱은 시간과 세기, 반만, 시간만, 세기만 | 음표 다듬기의 다른 도구와 같은 편집 하나 |
| 오디오에 입히기 | `quantizedWarp` 의 목표 자리를 그루브로 (`AudioQuantizeOptions::groove`) | 워프 마커가 어택을 옮긴다 |
| 내 그루브 | 앱 데이터 폴더의 `InitialDAW/Grooves/<이름>.json`. 음표 다듬기 > 그루브 입히기 > 이 음표로 그루브 저장, 클립 메뉴 > 어택으로 그루브 저장. 시험은 폴더를 시험 폴더로 바꾼다 | 효과 프리셋과 같은 자리 |
| 명령행 | `music-render groove list`, `groove extract <곡> --track <t> [--bars a-b]`, `groove extract-audio <오디오> --bpm <n> [--from <첫 박의 초>]` (`--grid`, `--length`, `--output`), `arrange <곡> groove <트랙> --groove <id 또는 파일> [--timing 100] [--velocity 100]` (오디오 트랙은 워프 마커) | |

## 4. 확인한 것

- 음표에서: 두 마디의 16분음표(엇박 +0.06 박, 세기 100 과 70)에서 뽑은 그루브가 어긋남 0, 0.06 과 세기 배수 1.176, 0.824. 곧은 16분음표(세기 80)에 입히면 4.31 박, 세기 94 와 66.
- 어택에서 (앱): 엇박이 30 ms 늦고 6 dB 작은 8분음표 루프의 그루브는 엇박 칸이 0.06 박 (0.01 안) 늦고 세기 배수가 정박보다 작다.
- 실제 드럼 (「새벽 세 시」의 킥, 스네어, 하이햇 9~12 마디, 94 BPM, 16분음표 스윙 26.6 ms = 0.042 박): 뽑은 그루브의 엇박 16분 칸이 +0.033~+0.043 박, 정박 칸이 -0.009~+0.009 박.
- 오디오 퀀타이즈의 그루브: 클립의 어택 마커가 그루브 자리(8분음표 60% 스윙)에 1e-6 박 안.

## 5. 남은 것

- 그루브를 화면에서 보고 칸마다 고치는 편집기, 길이(음표 끝)의 그루브는 없다.
- 그루브를 곡 전체의 재생 설정으로 두는 것(엔진의 `swing` 처럼 렌더 때 입히기)은 하지 않았다. 입힌 결과가 곡에 적혀 사람이 본다.
