# D28. 음높이 교정 (오디오 클립)

> 작성일: 2026-10-23. 계기: 상용 DAW 는 녹음한 목소리와 악기의 음높이를 가까운 반음이나 곡의 조의 음으로 고친다 (자동 교정).
> D22 의 음높이 따라가기(`trackPitch`)와 D16 의 클립 늘이기(Signalsmith Stretch)를 묶는다.

## 1. 목표

- 클립의 `pitchCorrection`: 잰 음높이를 가까운 허락된 음(반음, 또는 조나 음계의 음)으로 끌어온다.
- 세기(거리의 몫)와 빠르기(따라가는 시간: 0 이면 비브라토도 편다, 길면 꾸밈과 비브라토가 남는다), 포먼트 지키기.
- 클립 메뉴와 명령행.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 형식 | 클립의 `"pitchCorrection": { "strength", "speedMs", "formant", "key" }` 또는 `"scale"` 과 `"root"` (음계 id 는 `music-render scales`). 둘 다 없으면 반음마다 | 곡의 `key` 와 같은 글로 쓴다. 선법은 음계 표를 쓴다 |
| 곡선 | `pitchCorrectionCurve`: 5 ms 마다 잰 높이(YIN, 60~1500 Hz)에 클립의 `pitchSemitones` 를 더한 높이에서 가까운 허락된 음을 고르고 (앞 목표에서 0.65 반음 안이면 그대로: 경계의 떨림이 목표를 오가지 않는다), 거리에 세기를 곱한다. 높이가 없는 프레임(분명함 0.8 아래, 가장 큰 프레임보다 40 dB 넘게 작음)은 앞 값을 50 ms 붙들다 0. `speedMs` 의 한 극 거르개 | 자동 교정의 따라가기 시간 |
| 적용 | 클립 렌더(`renderStretched`)가 256 샘플마다 `setTransposeSemitones (pitchSemitones + 교정)`. 교정은 출력 지연만큼 뒤의 파일 자리에서 읽는다 | 바꾼 높이는 출력 지연(60 ms)만큼 뒤의 소리에 들린다. 같은 자리를 읽으면 5.5 Hz 비브라토가 줄지 않고 오히려 커졌다 (±16 에서 ±22 센트) |
| 포먼트 | `formant` (기본 켬)이면 `setFormantFactor (1, true)` 에 잰 기본 주파수를 `setFormantBase` 로 준다 | Signalsmith 가 기본 주파수를 스스로 재게 두면 0.7 반음 교정이 0.4초 뒤 원래 높이로 돌아갔다 |
| 함께 쓰기 | `warpMode: slice` 와 함께 쓸 수 없다 (자른 조각은 늘이지 않는다). 워프 마커, 템포 따르기, `pitchSemitones` 와는 함께 | |
| 화면 | 클립 메뉴 > 음높이 교정: 끄기, 가까운 반음으로, 곡의 조 음으로 (곡에 `key` 가 없으면 음표로 추정한 조, 음표도 없으면 끈다)마다 빠르게 (0 ms), 보통 (30 ms), 자연스럽게 (80 ms), 세기 100~25%, 포먼트 지키기 | |
| 명령행 | `music-render arrange song.json tune <트랙> [--strength 100] [--speed 30] [--key "A minor" \| --scale dorian --root D] [--no-formant] [--clip <n>]`, `untune <트랙>` | |

## 4. 확인한 것

- 만든 목소리 (배음 15개와 700, 1200 Hz 의 두 포먼트): A3 +35, C4 -40, C#4 +30 센트, E4 의 5.5 Hz ±25 센트 비브라토.
  - 빠르게 (0 ms): 고른 음이 +0.9~+1.2 센트, 비브라토의 흔들림이 표준 편차 16.5 에서 4.0 센트.
  - 세기 50%: +35 가 +18.8, -40 이 -18.9 센트.
  - 자연스럽게 (120 ms): 고른 음은 -3.1~+3.7 센트, 비브라토는 14.5 센트로 남는다.
  - A minor: C# +30 이 D 로 (+1.2 센트). 0.3 반음 옮긴 클립은 옮긴 높이(A3 +65)에서 가까운 Bb3 에 맞춘다.
  - 실시간 재생이 오프라인과 1e-5 안.
- 실제 녹음 (「새벽 세 시」의 테너 색소폰 스템 20초, FreePats 녹음): 30 센트 올린 소리는 프레임의 1% 만 반음에서 ±10 센트 안 (중앙값 31.1 센트).
  교정하면 빠르게 93% (중앙값 1.2 센트), 보통 89%, 자연스럽게 86%. 원래 녹음은 96%.

## 5. 남은 것

- 음마다 높이를 끌어 고치는 편집기(음 덩어리와 높이 곡선을 피아노 롤에 그리기)는 D36 에서 했다 ([d36-note-pitch.md](d36-note-pitch.md)).
- 실시간 입력에 거는 교정 효과(모니터링하며 듣기)는 없다.
- 실제 목소리 녹음으로는 재지 않았다 (저자의 녹음으로 들어 볼 것).
