# D22. 멜로디 받아 적기 (오디오에서 음표로)

> 작성일: 2026-10-23. 계기: 상용 DAW 는 부르거나 연주한 단선율 녹음을 MIDI 음표로 바꾼다. 마이크로 흥얼거린 선율을
> 고칠 수 있는 음표로 남긴다.
> 오디오 생성 모델이 아니라 신호 처리(음높이 재기)다.

## 1. 목표

오디오 클립(그 클립이 재생하는 파일 구간)이나 파일의 단선율을 음표로 받아 적는다. 높이, 시작, 길이, 세기를 정하고 곡의 박에 놓는다.

## 2. 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 음높이 | YIN: 40 ms 창, 5 ms 마다, 50~2000 Hz. 차이 함수는 FFT 상관(창 하나와 창 + 최대 지연의 곱)과 제곱의 누적 합으로 구한다. 문턱 0.15, 포물선 보간 (`analysis/PitchTrack`) | 바로 구하면 1초에 프레임마다 백만 번 곱한다. 퀵 샘플러의 높이 재기도 같은 함수를 쓴다 |
| 버금 후보 | 프레임마다 비주기성의 다른 골(0.5 아래, 고른 주기의 배수는 빼고) 셋 | 두 음이 겹친 자리에서 약한 쪽이 보인다 |
| 소리 있음 | 높이가 있고 분명함 0.8 위, 크기가 가장 큰 프레임에서 35 dB 안이고 -60 dBFS 위 | |
| 옥타브 튐 | 앞뒤 세 프레임의 중앙값과 옥타브만큼 다르면 옮긴다. 앞 높이보다 한 옥타브 넘게 낮은 프레임은 두 음이 겹친 자리의 긴 공통 주기라 앞 높이 가까운 버금 후보로 바꾸고, 없으면 높이 없음 (30 ms 넘게 이어지면 진짜 도약) | 레가토 클라리넷의 음 사이에서 3옥타브 아래 높이가 50 ms 잡혔다 |
| 음 나누기 | 30 ms 넘는 소리 없음, 높이 바뀜(0.7 반음 넘게 40 ms, 마지막 네 프레임이 1 반음 안에 자리 잡으면 확정. 앞 음의 높이가 끝난 자리에서 나누고, 새 높이가 버금 후보로 먼저 들리면 150 ms 까지 거슬러 간다), 다시 치는 어택(20 ms 안에 6 dB 넘게 오르면 앞의 가장 작은 자리에서) | |
| 음 | 높이는 프레임 높이의 중앙값을 반올림, 60 ms 보다 짧으면 버린다. 쉼 뒤의 음은 높이가 잡히기 전 소리가 차오른 자리(봉우리 -15 dB, 20 ms 까지)로 당긴다. 세기는 가장 큰 음을 100 으로 1 dB 에 1.5 | 비브라토는 중앙값이 가운데를 잡는다 |
| 곡에 넣기 (앱) | 클립 메뉴 > 멜로디를 음표로 (새 트랙): 파일의 초를 `clipSongSecondsAt` 로 곡의 초(늘인 클립도), 템포 지도로 박. 음높이를 바꾼 클립은 들리는 높이. 악기는 그랜드 피아노(없으면 `synth.piano`), 트랙 이름 "<파일> melody", 음표는 `"humanize": false`. 편집 하나 | 연주의 흔들림이 이미 있다. 박에 맞추기는 피아노 롤의 양자화(D12)가 한다 |
| 명령행 | `music-render transcribe <오디오> --output <곡.json> [--bpm 120] [--instrument grand-piano] [--from 초] [--seconds 초]`: 받아 적은 구간의 처음이 0 박인 새 곡 | 생성기와 에이전트도 쓴다 |

## 4. 확인한 것

- 만든 소리 (배음 다섯, -66 dBFS 잡음): 쉼 뒤의 C4, 레가토 E4, 쉼 뒤의 G4, 같은 G4 를 다시 치기, ±30 센트 비브라토의 A4, 12 dB 여린 D3 가
  여섯 음 모두 맞는 높이로, 시작과 끝 오차가 가장 크게 5 ms. 여린 음의 세기 83 (나머지 99~100), 비브라토 음의 중앙값 +1.8 센트. 잡음과 무음은 음이 없다.
- 실제 샘플 악기 (곡의 선율 트랙만 렌더링해 받아 적고 곡의 음과 견줌):
  - 「늦은 편지」 3판의 그랜드 피아노 선율 (341음, 옥타브 겹침 21곳): 음 시작의 95.0% 가 80 ms 안, 시작 오차 중앙값 2.5 ms (90% 가 9.7 ms).
    가장 가까운 음의 높이가 313 개 같고, 다른 것은 대부분 옥타브 겹침 자리의 다른 성부(-12 가 20 개).
  - 「녹슨 날개」의 클라리넷 선율 (247음, 3분 53초를 2.1초에 받아 적는다): 가장 가까운 음 241 개의 높이가 모두 같다 (옥타브 틀림 없음).
    시작은 늦게 잡힌다: 부호 있는 오차 중앙값 +63 ms (10% +41, 90% +98). 레가토의 새 음은 공격이 느려 앞 음의 울림이 50 ms 남짓 우세하다
    (22.22초의 B4 는 22.265초까지 앞 음 A4 의 높이). 버금 후보로 거슬러 가기와 엉뚱한 높이 거르기로 중앙값 +72 에서 +63 ms 로, 80 ms 안의 일치가 54% 에서 61% 로.
- 앱: 2 박의 클립(파일 0.65초부터 1.3초)에서 C5 와 E5 가 2.1 박과 3.3 박에, 반음 둘 올린 클립은 D5 로, 잡음 클립은 트랙을 만들지 않고 알린다, 실행 취소.
- 저자의 목소리나 악기 녹음으로는 아직 재지 않았다 (저자가 확인한다).

## 5. 남은 것

- 여러 음이 함께 울리는 녹음(화음, 페달을 밟은 피아노)은 받아 적지 못한다 (한 높이만 낸다).
- 음 사이의 미끄러짐과 비브라토를 피치 벤드 곡선으로 옮기기, 타악기 녹음을 드럼 음표로 바꾸기(어택 찾기)는 없다.
- 공격이 느린 악기의 시작이 늦게 잡히는 것: 박에 맞추는 양자화가 앞 칸으로 보내도록, 늦음을 재서 당기는 길은 아직 없다.
